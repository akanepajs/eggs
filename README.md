# eggs.kanepajs.eu

English mirror of the cage-free Latvian eggs page.

The content and data are built and maintained in the source repo:
https://github.com/akanepajs/olas

That repo's daily scrape rebuilds `index_en.html`; the `sync-en` workflow here
fetches it and republishes it to `eggs.kanepajs.eu`. The Latvian version lives at
https://olas.kanepajs.eu
